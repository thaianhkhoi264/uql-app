# uql-app

A visual query builder for [uma.moe](https://uma.moe)'s **UQL** — the query language ("SQL for your umas") behind its inheritance database search.

uma.moe's Advanced filter can only AND conditions together. This app builds a UQL query with OR support (for example "2–3★ Mile + 5–6★ Turf **or** 2–3★ Turf + 5–6★ Mile"), shows the generated text live, and lets you copy it into uma.moe's UQL box. It also works in reverse: paste a query and the controls fill themselves in.

## What it does

- Pick **Main** and **GP** characters from the current global roster.
- Filter **blue, pink, green and white sparks**, either anywhere in the lineage (up to 9★) or on the main parent only (up to 3★).
- Each spark can be a specific one, **Any**, or **Custom…** (a hand-picked subset sharing one star range).
- Sparks inside a group are AND'd (up to 3 per group); extra groups are OR alternatives. Groups can be duplicated or flipped.
- Add soft-ranking **preferred white skills** with priority groups.
- Copy the generated query, or paste one to load it back into the controls.

Example output:

```
(Main Stamina >= 2 or Main Power >= 2)
((overlaps(blue_sparks, (305, 306)) and overlaps(blue_sparks, (205, 505, 206, 506))))
```

## Run it

Requires Node `^20.19.0` or `>=22.12.0`.

```bash
npm ci
npm run dev       # dev server with hot reload
npm run build     # type-check + build to dist/index.html
npm run lint      # oxlint
```

`npm run build` produces a single self-contained `dist/index.html` (JS, CSS and data inlined) with no server-side part.

## How it's built

React 19 + TypeScript + Vite 8, linted with oxlint. [`vite-plugin-singlefile`](https://github.com/richardtallent/vite-plugin-singlefile) inlines everything into one HTML file.

```
src/uql/         state model, compiler (state -> UQL), parser (UQL -> state)
src/components/  filter controls and the UQL preview/editor box
src/data/        spark and character tables, and the script that regenerates them
```

The compiler and parser are plain functions with no UI dependencies. The parser only understands the query shapes the compiler produces (character lists, spark comparisons, and `optional white` ranking clauses); anything else is reported as a warning rather than guessed at.

### Data

`src/data/*.json` (spark names, character names, icon filenames) is generated by `node src/data/prep.mjs` from uma.moe's public resource feed at `https://uma.moe/resources/current/`. Re-run it to pick up new game content. Character portraits and spark icons are loaded from uma.moe at runtime rather than bundled.
